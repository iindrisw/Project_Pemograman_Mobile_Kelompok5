# 🥐 Chikara Bakery - Mobile App

Aplikasi mobile toko roti "Chikara Bake" yang dikembangkan menggunakan **React Native** dan **Expo**. Proyek ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Mobile / Sistem Berbasis Bergerak (serta riset *Hybrid Filtering* untuk jurnal).

---

## 🚀 Fitur Utama
* **Onboarding & Splash Screen**: Pengenalan brand dengan desain interaktif.
* **Katalog Menu & Kategori**: Menampilkan pilihan produk roti, pastri, kue, dan minuman.
* **Keranjang Belanja & Checkout**: Mengelola item belanja secara *real-time*.
* **Riwayat Pesanan**: Memantau status pesanan (dalam proses / terkirim).
* **Multi-Theme Support**: Mendukung mode terang (*light mode*) dan gelap (*dark mode*).
